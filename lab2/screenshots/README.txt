# ResQNet Lab 2 - Screenshot Submission Guide

Please capture the following 5 screenshots from Google Chrome and place them in this folder before final submission:

1. 01-desktop.png
   - Description: Full desktop view (>=1024px width) showing the header, emergency banner, contextual status, and incident cards.
   - How to capture: Open lab2/index.html in Chrome, maximize the window or press F12 > Ctrl+Shift+P > "Capture full size screenshot" or "Capture screenshot".

2. 02-mobile-320px.png
   - Description: Mobile view at exactly 320px width (iPhone SE / narrow viewport).
   - How to capture: In Chrome DevTools (F12), toggle Device Toolbar (Ctrl+Shift+M), set dimensions to 320 x 568, and capture screenshot.

3. 03-high-contrast.png
   - Description: High Contrast / Forced Colors view showing prominent borders and accessible status indicators.
   - How to capture: In Chrome DevTools (F12) > More Tools > Rendering > "Emulate CSS media feature forced-colors" set to "active".

4. 04-reduced-motion.png
   - Description: View with prefers-reduced-motion active, showing all emergency pulses disabled and static badges visible.
   - How to capture: In Chrome DevTools (F12) > More Tools > Rendering > "Emulate CSS media feature prefers-reduced-motion" set to "reduce".

5. 05-print-preview.png
   - Description: A4 Emergency Incident Report print layout.
   - How to capture: Press Ctrl+P (Print) in Chrome, select "Save as PDF" or preview, and capture a screenshot showing the clean A4 disaster report format with URLs printed and screen clutter hidden.
