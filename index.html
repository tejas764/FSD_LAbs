⚡ Offline-First Architecture & Data Resilience

1. Service Worker Caching

Pre-caches core app shell, local Leaflet mapping engine, and compiled Tailwind CSS. The app boots in milliseconds without requesting a single byte over the Internet.

2. IndexedDB ACID Storage

Stores complete operational entities (reports, rescue teams, supply inventory, hospital beds, and audit logs) directly in the client browser with indexed query capabilities.

3. Background Sync Queue

Mutations executed during network disruption are recorded in the sync queue. Once connectivity resumes, changes replay cleanly to central command without data loss.

ResQNet: Offline-First Disaster Relief Coordination System

Designed and engineered as a disaster-resilient, offline-first progressive web platform. ResQNet addresses the severe communication blackout that typically follows cyclones, earthquakes, and floodings by decoupling client application functionality from server availability.

HTML5 / CSS3 / Vanilla JS Local Tailwind CSS Build IndexedDB ACID Storage Service Worker Caching Leaflet.js Tactical GIS

📐 Offline-First Architectural Topology

Layer 1: User / Edge Device

Field Responder UI

Responsive Single Page Application with interactive dashboard, incident reporting forms, team dispatchers, and inventory controls.

Vanilla JS & Tailwind
Layer 2: App Shell Cache

Service Worker Engine

Intercepts all HTTP fetch events. Serves pre-cached assets (HTML, CSS, JS, Leaflet icons) without network reliance.

Cache-First Strategy
Layer 3: Local Storage

IndexedDB ACID Engine

Stores structured objects in stores: reports, teams, resources, shelters, and syncQueue.

IndexedDB (Indexed Querying)
Layer 4: Reconciliation

Background Sync Engine

Monitors navigator.onLine. Buffers mutations in sync queue and replays batch updates when internet connectivity returns.

Sync Queue Replay

🛡️ Zero CDN Dependency for Styling & Mapping

All stylesheet classes are statically generated via the local Tailwind CSS build CLI tool. Leaflet.js JavaScript and stylesheet files are self-hosted in the /dist directory. The application guarantees 100% functionality even on completely air-gapped computers and isolated tablets.

🗺️ Tactical Spatial Vector Fallback

Unlike typical web maps that break or show empty gray squares when offline, ResQNet includes a custom tactical vector mode with district boundaries, coordinate scales, flood polygons, and spatial pins. It does not falsely claim live satellite tiles exist when offline.

🔄 Offline Mutation Tracking & Replay Queue

When users submit new emergency reports or update inventory quantities offline, the system assigns a unique cryptographic ID, stores the mutation in the local IndexedDB, and tags the item as Pending Synchronization. The interactive toggle allows immediate demonstration during project defense.

📱 Progressive Web App (PWA) Standard

Includes a W3C Web App Manifest with icons, standalone display mode, and Service Worker registration. The system can be installed directly to desktop or mobile home screens like a native app.
